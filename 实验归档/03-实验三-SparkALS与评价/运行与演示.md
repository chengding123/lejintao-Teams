# 实验三运行与演示

## 直接演示（本机已有 Docker 镜像与数据库）

1. 启动 Docker Desktop，确认使用 Linux 容器模式；不要重新初始化数据库、删除卷或升级操作系统。
2. 双击项目内 `scripts/experiment3/start-experiment3.bat`。它在保留教师 `compose.yaml` 的前提下叠加实验三学生镜像版本，并等待 API、网页健康。
3. 打开 `http://127.0.0.1:8080/experiments?source=ml&algorithm=als&user=14`。如页面缓存旧版，可按 Ctrl+F5。
4. 选择历史用户 `ml:14`，依次切换 Popular、Content、ItemCF、ALS，展示各自真实 Top-10 和下方统一 validation 表的 Precision@10、Recall@10。
5. 切到 `ml:55` 的 ItemCF 或 ALS，证明推荐随真实评分历史变化；切换冷启动与类型偏好，解释它在单独的 cold 用户集合上评价。
6. 指出 `模型版本 spark-als-explicit-v1`、准确率的定义、ALS 评分拟合与 Top-N 命中的区别，并如实说明本次 ALS 命中率低于 ItemCF。
