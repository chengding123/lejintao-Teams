# 推荐系统课程实验归档

本仓库保存推荐算法课程实验一、实验二的阶段性可提交材料，按实验编号分开归档，避免后续实验覆盖早期结果。

## 目录

- `实验归档/01-实验一-系统认知与内容推荐/`：实验一记录、实验一源码快照与相关测试。
- `实验归档/02-实验二-冷启动与ItemCF/`：Popular、Cold Start、ItemCF 的源码快照，实验记录、技术说明、API 验收结果，以及四张正式验收截图。

## 实验二算法说明

- Popular：根据 MovieLens 训练评分数据的热度与评分统计生成热门推荐。
- Cold Start：无行为用户默认回退到热门榜；提供类型兴趣筛选的个性化冷启动策略。
- ItemCF：使用真实评分/收藏历史计算物品相似度，为不同历史用户生成个性化结果。
